# Teoremas_Algebra_Booleana

Los teoremas permiten simplificar expresiones booleanas. La PPT presenta los siguientes resultados fundamentales. fileciteturn0file0L164-L169 fileciteturn0file0L227-L236

| ID | Teorema | Nombre |
|---|---|---|
| T1 | `B · 1 = B` | Identity |
| T2 | `B · 0 = 0` | Null Element |
| T3 | `B · B = B` | Idempotency |
| T4 | `¬(¬B) = B` | Involution |
| T5 | `B · ¬B = 0` | Complement |
| T6 | `B · C = C · B` | Commutativity |
| T7 | `(B · C) · D = B · (C · D)` | Associativity |
| T8 | `B · (C + D) = B·C + B·D` | Distributivity |
| T9 | `B · (B + C) = B` | Covering / Absorption |
| T10 | `(B·C) + (B·¬C) = B` | Combining |
| T11 | `(B·C) + (B·D) + (C·D) = (B·C) + (B·D)` | Consensus |

El material destaca que la distributividad booleana incluye también una forma en la que OR distribuye sobre AND, a diferencia de la presentación habitual del álgebra tradicional. fileciteturn0file0L290-L304
