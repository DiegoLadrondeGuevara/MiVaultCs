# Forma_Canonica

Una **forma canónica** es una representación estándar de una expresión booleana que proporciona una firma algebraica única. Aunque una función tiene una tabla de verdad única, puede tener múltiples expresiones equivalentes; la forma canónica fija una representación estándar. fileciteturn0file0L394-L403

Las dos formas tratadas son:

- [[Forma_SOP]]: suma de minterminos.
- [[Forma_POS]]: producto de maxterminos.

La PPT advierte que la forma canónica **no equivale necesariamente a la forma mínima**. fileciteturn0file0L568-L579
